# Руководство по локализации

Этот документ содержит рекомендации по реализации и поддержке локализации в приложении Transmission Client.

## Обзор

Приложение поддерживает несколько языков через пользовательскую систему локализации, основанную на файлах переводов в формате JSON. Это гарантирует, что пользователи могут взаимодействовать с приложением на предпочитаемом языке.

## Поддерживаемые языки

На данный момент приложение поддерживает:

- Английский (en) - язык по умолчанию
- Русский (ru)

## Структура каталогов

```
transmission-client-go/
├── locales/
│   ├── en.json      # Английские переводы
│   └── ru.json      # Русские переводы
├── internal/
│   └── infrastructure/
│       └── localization_service.go  # Сервис локализации на бэкенде
└── frontend/
    └── src/
        └── contexts/
            └── LocalizationContext.tsx  # Контекст локализации на фронтенде
```

## Архитектура

Система локализации реализована с использованием следующих компонентов:

1. **Сервис бэкенда (`localization_service.go`)**:
   - Загружает файлы переводов
   - Определяет системный язык
   - Предоставляет функции перевода для Go-кода
   - Предоставляет переводы для фронтенда

2. **Контекст фронтенда (`LocalizationContext.tsx`)**:
   - Предоставляет React-компонентам возможности перевода
   - Управляет выбором языка
   - Форматирует переводы с параметрами

## Добавление новых переводов

### Добавление новой строки

При добавлении новой строки пользовательского интерфейса в приложение:

1. Добавьте строку в `locales/en.json` с описательным ключом:

```json
{
  "common.buttons.save": "Save",
  "common.buttons.cancel": "Cancel",
  "feature.newKey": "Your new string here"
}
```

2. Добавьте соответствующий перевод для всех поддерживаемых языков (например, `locales/ru.json`):

```json
{
  "common.buttons.save": "Сохранить",
  "common.buttons.cancel": "Отмена",
  "feature.newKey": "Ваша новая строка здесь"
}
```

### Соглашения по именованию ключей

Используйте точечную нотацию с осмысленной иерархией:

- `common.buttons.save` - Общий элемент UI
- `errors.connection.timeout` - Сообщение об ошибке
- `torrent.status.downloading` - Контент, специфический для функциональности
- `settings.tabs.general` - Раздел настроек

## Использование переводов

### В бэкенде на Go

```go
// Простой перевод
message := a.localizationService.Translate("errors.connection.failed", locale)

// Перевод с параметрами
message := a.localizationService.Translate("errors.file.notFound", locale, filePath)
```

### Во фронтенде на React

```tsx
import { useLocalization } from '../contexts/LocalizationContext';

const MyComponent = () => {
  const { translate } = useLocalization();
  
  return (
    <div>
      <h1>{translate('feature.title')}</h1>
      <p>{translate('feature.description', { count: 5 })}</p>
      <button>{translate('common.buttons.save')}</button>
    </div>
  );
};
```

## Форматирование параметров

Переводы могут включать параметры, которые будут заменены во время выполнения:

### В JSON-файлах

```json
{
  "torrent.count": "Найдено {{count}} торрентов",
  "torrent.added": "Добавлен торрент: {{name}}"
}
```

### В коде на Go

```go
// Массив аргументов заменит {{0}}, {{1}} и т.д.
message := a.localizationService.Translate("torrent.added", locale, torrentName)
```

### В коде на React

```tsx
// Именованные параметры поддерживаются во фронтенде
const message = translate('torrent.count', { count: torrents.length })
```

## Выбор языка

Приложение автоматически определяет системный язык при первом запуске. Пользователи могут изменить язык в настройках.

### Сохранение выбора языка

Выбранный язык сохраняется в:

1. Конфигурации приложения
2. Локальном хранилище (фронтенд)

При изменении языка интерфейс обновляется немедленно без необходимости перезапуска.

## Лучшие практики

1. **Избегайте конкатенации строк**: Вместо объединения строк используйте параметры.

   ```tsx
   // ❌ Плохо
   translate('torrent.status') + ": " + translate('torrent.downloading')
   
   // ✅ Хорошо
   translate('torrent.statusWithState', { state: translate('torrent.downloading') })
   ```

2. **Предоставляйте контекст**: Используйте описательные ключи, указывающие, где/как используется строка.

3. **Поддерживайте порядок в переводах**: Группируйте связанные переводы вместе и поддерживайте логичную иерархию.

4. **Тестируйте с разными языками**: Проверяйте макет интерфейса с языками, которые могут быть значительно длиннее английского.

5. **Обрабатывайте множественное число**: Для счетных элементов при необходимости предоставляйте варианты для разного количества.

## Устранение проблем

Если перевод отсутствует:

1. Приложение вернется к английской версии
2. В режиме разработки будет отображаться предупреждение в консоли
3. Проверьте, существует ли ключ во всех языковых файлах

## Добавление нового языка

Чтобы добавить поддержку нового языка:

1. Создайте новый файл в каталоге `locales/` (например, `fr.json` для французского)
2. Скопируйте содержимое из `en.json` и переведите все строки
3. Добавьте новый язык в список доступных языков в сервисе локализации
4. Добавьте соответствующий интерфейс для выбора нового языка в настройках

## Тестирование локализации

Перед фиксацией новых переводов:

1. Проверьте, что все строки переведены
2. Проверьте наличие ошибок форматирования
3. Протестируйте интерфейс с новым языком, чтобы убедиться, что макет работает корректно
4. Проверьте, что замена параметров работает корректно
