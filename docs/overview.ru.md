# Обзор проекта

## Введение

Remote Transmission Desktop Client - это современный настольный клиент для Transmission BitTorrent, разработанный для предоставления удобного интерфейса для управления торрентами. Построенный на Go и React с использованием фреймворка Wails, он предлагает удобный опыт для пользователей, которые хотят эффективно взаимодействовать со своим Transmission сервером.

## Ключевые возможности

### Пользовательский интерфейс

- **Современный дизайн**: Чистый и интуитивно понятный интерфейс, созданный с помощью React
- **Тёмная/светлая тема**: Поддержка как тёмной, так и светлой тем
- **Локализация**: Полная поддержка английского и русского языков

### Управление торрентами

- **Список торрентов**: Просмотр всех ваших торрентов с подробной информацией
- **Добавление торрентов**: Добавление торрентов через URL или локальный файл
- **Управление файлами**: Выбор, какие файлы загружать в торрентах
- **Пакетные операции**: Выполнение операций над несколькими торрентами одновременно
- **Подробная информация**: Просмотр детальной статистики для каждого торрента

### Функции соединения

- **Автоматическое переподключение**: Интеллектуальная система переподключения с управлением тайм-аутами
- **Обратная связь о статусе соединения**: Визуальное отображение состояния соединения с информативными сообщениями
- **Обработка тайм-аутов**: Корректная обработка тайм-аутов соединения с удобными для пользователя уведомлениями

### Управление производительностью

- **Ограничение скорости**: Ограничение скорости загрузки и отдачи
- **Автоостановка сидирования**: Настройка максимального соотношения отдачи для автоматической остановки сидирования
- **Управление путями загрузки**: Управление и сохранение путей загрузки для быстрого доступа

### Интеграция

- **Нативная интеграция с macOS**: Поддержка файловых ассоциаций macOS и системных событий
- **Безопасное соединение**: Безопасное подключение к вашему серверу Transmission

## Технологический стек

- **Бэкенд**: Язык программирования Go
- **Фронтенд**: React с TypeScript
- **Фреймворк**: Wails (Go + веб-технологии)
- **Управление состоянием**: React Context API
- **Стилизация**: CSS модули
- **Локализация**: Пользовательская система локализации с переводами на основе JSON
- **Сборка**: Система сборки Wails с Vite

## Архитектура

Приложение следует подходу чистой архитектуры с чётким разделением ответственности:

- **Слой предметной области (Domain Layer)**: Основная бизнес-логика и сущности
- **Слой приложения (Application Layer)**: Сервисы приложения, оркестрирующие домен
- **Слой инфраструктуры (Infrastructure Layer)**: Реализация внешних сервисов
- **Слой пользовательского интерфейса (User Interface Layer)**: Компоненты React и представления

Для более детальной информации об архитектуре, пожалуйста, обратитесь к [Документу по архитектуре](architecture.ru.md).

## Целевая аудитория

Это приложение разработано для:

- Пользователей, предпочитающих настольное приложение веб-интерфейсам
- Пользователей, желающих современный, функционально богатый клиент для Transmission
- Пользователей macOS, желающих нативную интеграцию с их операционной системой

## Текущий статус

Приложение находится в активной разработке с фокусом на поддержку macOS. Оно включает все основные функции для управления торрентами, сохраняя при этом удобный для пользователя интерфейс.
