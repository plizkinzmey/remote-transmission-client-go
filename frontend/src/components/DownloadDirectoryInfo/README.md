# DownloadDirectoryInfo

Компонент для отображения информации о директории загрузки торрента.

## Особенности
- Компактное отображение пути к директории загрузки
- Обрезка длинных путей с поддержкой полного пути в тултипе
- Визуальное оформление с иконкой папки
- Условный рендеринг (компонент не отображается, если путь не указан)
- Интеграция с системой тем Radix UI

## API

### Props

| Prop | Тип | Описание |
|------|-----|----------|
| `path` | `string` | Путь к директории загрузки |

## Примеры использования

```tsx
import { DownloadDirectoryInfo } from '../DownloadDirectoryInfo';

// Базовое использование
<DownloadDirectoryInfo path="/home/user/downloads/torrents" />

// При пустом пути компонент не будет отображаться
<DownloadDirectoryInfo path="" />
```

## Зависимости
- @radix-ui/themes (Flex, Text)
- @heroicons/react/24/outline (FolderIcon)
- Локализация через useLocalization

## Стилевые особенности
- Светлый фон для визуального отделения от других элементов интерфейса
- Бордер снизу для отделения от содержимого
- Текст пути с поддержкой выделения для копирования (selectable-text)
- Обрезка длинных путей через text-overflow: ellipsis
- Полный путь доступен при наведении в виде тултипа

## Примечания
- Компонент применяет цвет фона из переменных темы (--background-secondary)
- При пустом пути (`path === ""`) компонент возвращает `null` и не рендерится
- Локализация текста "Директория загрузки" через систему локализации
