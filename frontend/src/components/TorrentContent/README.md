# TorrentContent

Модальный компонент для отображения содержимого торрента, включая дерево файлов и директорий с возможностью выбора файлов для загрузки.

## Особенности
- Отображение файловой структуры торрента в виде иерархического дерева
- Управление выбором файлов для загрузки
- Отображение прогресса загрузки для каждого файла и директории
- Отображение размеров файлов и директорий
- Возможность сворачивания/разворачивания директорий
- Показ директории загрузки торрента
- Интеграция с системой тем Radix UI
- Асинхронная загрузка данных с поддержкой состояний загрузки и ошибок
- Адаптивный дизайн

## API

### Props

| Prop | Тип | Описание |
|------|-----|----------|
| `id` | `number` | ID торрента |
| `name` | `string` | Название торрента |
| `onClose` | `() => void` | Обработчик закрытия диалога |

## Внутренняя структура

Компонент состоит из нескольких подкомпонентов:
1. `TorrentContentHeader` - Заголовок с названием торрента и кнопкой закрытия
2. `DownloadDirectoryInfo` - Информация о директории загрузки
3. `SelectAllFiles` - Чекбокс для выбора/отмены выбора всех файлов
4. `FileNode` - Компонент для отображения отдельного файла или директории

Данные загружаются и обрабатываются с помощью хуков:
- `useTorrentFiles` - Получение и управление файлами торрента
- `useDownloadDirectory` - Получение директории загрузки торрента

## Примеры использования

```tsx
import { TorrentContent } from '../TorrentContent';

// Использование компонента
<TorrentContent 
  id={123}
  name="Ubuntu 22.04 LTS"
  onClose={() => console.log('TorrentContent closed')}
/>
```

## Потоки данных

1. **Получение данных**:
   - При монтировании компонента вызываются API для получения списка файлов и директории загрузки
   - Данные обрабатываются и преобразуются в структуру дерева

2. **Взаимодействие**:
   - Выбор файла или директории вызывает API для изменения состояния файлов на сервере
   - Результаты обновляются в локальном состоянии для мгновенной обратной связи

3. **Закрытие**:
   - При закрытии диалога вызывается обработчик onClose
   - Разблокируется прокрутка основного интерфейса

## Пример данных

Компонент работает со следующей структурой данных от API:

```typescript
interface TorrentFile {
  ID: number;
  Name: string;
  Path: string;
  Size: number;
  Progress: number;
  Wanted: boolean;
}
```

Эти данные преобразуются во внутреннюю структуру FileNode для построения иерархического дерева.

## Примечания
- Компонент автоматически блокирует прокрутку основного интерфейса при открытии
- Поддерживает отображение больших деревьев файлов
- При открытии директории её содержимое отображается с отступом для визуальной иерархии
