# TorrentContentHeader

Компонент заголовка для модального окна содержимого торрента. Отображает название торрента и кнопку закрытия.

## Особенности
- Адаптивное отображение названия торрента с обрезкой при переполнении
- Поддержка длинных названий с отображением полного текста в тултипе
- Кнопка закрытия диалога
- Интеграция с системой тем Radix UI
- Полная доступность для управления с клавиатуры и скринридеров

## API

### Props

| Prop | Тип | Описание |
|------|-----|----------|
| `torrentName` | `string` | Название торрента для отображения |
| `onClose` | `() => void` | Обработчик закрытия диалога |

## Примеры использования

```tsx
import { TorrentContentHeader } from '../TorrentContentHeader';

// Использование компонента
<TorrentContentHeader 
  torrentName="Ubuntu 22.04 LTS (Jammy Jellyfish)"
  onClose={() => console.log('Closing dialog')}
/>
```

## Зависимости
- @radix-ui/themes (Heading, IconButton)
- @heroicons/react/24/outline (XMarkIcon)
- Локализация через useLocalization

## Стилевые особенности
- Фиксированная высота для стабильного лейаута
- Бордер снизу для отделения от содержимого
- Обрезка названия торрента через text-overflow: ellipsis
- Отображение полного названия в тултипе при наведении

## Примечания
- Компонент адаптируется к различным размерам контейнера
- Доступность обеспечивается через семантический HTML и ARIA атрибуты
- Кнопка закрытия имеет локализованную подсказку
