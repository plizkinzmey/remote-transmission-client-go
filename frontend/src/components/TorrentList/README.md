# TorrentList

Компонент для отображения списка торрентов с возможностью фильтрации и управления.

## Использование

```tsx
import { TorrentList } from './components/TorrentList';

function App() {
  const [selectedTorrents, setSelectedTorrents] = useState(new Set<number>());
  
  return (
    <TorrentList
      torrents={torrents}
      searchTerm="ubuntu"
      selectedTorrents={selectedTorrents}
      onSelect={(id) => {/* обработка выбора */}}
      onRemove={(id, deleteData) => {/* обработка удаления */}}
      onStart={(id) => {/* запуск торрента */}}
      onStop={(id) => {/* остановка торрента */}}
    />
  );
}
```

## API

### Props

| Проп | Тип | По умолчанию | Описание |
|------|-----|--------------|----------|
| torrents | TorrentData[] | - | Массив торрентов для отображения |
| searchTerm | string | - | Строка для фильтрации торрентов |
| selectedTorrents | Set<number> | - | Множество ID выбранных торрентов |
| onSelect | (id: number) => void | - | Callback выбора торрента |
| onRemove | (id: number, deleteData: boolean) => void | - | Callback удаления торрента |
| onStart | (id: number) => void | - | Callback запуска торрента |
| onStop | (id: number) => void | - | Callback остановки торрента |
| onVerify | (id: number) => void | - | Callback проверки торрента |
| isLoading | boolean | false | Флаг загрузки данных |
| isReconnecting | boolean | false | Флаг переподключения |
| onSetSpeedLimit | (id: number, isSlowMode: boolean) => void | - | Callback установки ограничения скорости |

### TorrentData

```typescript
interface TorrentData {
  ID: number;              // Уникальный идентификатор
  Name: string;            // Название торрента
  Status: string;          // Статус
  Progress: number;        // Прогресс загрузки (0-100)
  Size: number;           // Размер в байтах
  SizeFormatted: string;  // Отформатированный размер
  // ... другие поля
}
```

## Особенности реализации

1. Производительность
   - Используется `useMemo` для оптимизации фильтрации
   - Минимизировано количество перерисовок

2. Доступность
   - Все интерактивные элементы имеют data-testid
   - Поддерживается клавиатурная навигация

3. Состояния
   - Загрузка: отображается спиннер
   - Пустой список: информационное сообщение
   - Отсутствие результатов поиска: специальное сообщение
   - Переподключение: пустой рендер

## Тестирование

Компонент покрыт юнит-тестами, которые проверяют:
- Корректный рендер списка
- Фильтрацию торрентов
- Отображение различных состояний
- Обработку переподключения

## Стилизация

Стили изолированы в CSS модуле и поддерживают:
- Адаптивный дизайн
- Темную/светлую темы через CSS переменные
- Анимации при изменении состояний

## Примечания

1. При изменении компонента необходимо:
   - Обновить тесты
   - Проверить все состояния
   - Убедиться в работе фильтрации

2. Возможные улучшения:
   - Виртуализация списка для большого количества торрентов
   - Добавление сортировки
   - Улучшение анимаций переходов между состояниями
